# Alaska-Aviation-Data-Explorer
The Alaska Aviation Data Explorer will be a Django web app that makes it easier to look through Alaska flight data and see information about routes, delays, cancellations, and airlines. The app is for travelers, students, or anyone interested in Alaska aviation who wants a simpler way to explore the data. Users will be able to browse and search flights, filter them by things like airport or airline, view basic flight and route statistics, and save personal notes about flights they are interested in. The database will store flight information such as the date, airline, origin, destination, departure and arrival delays, cancellation status, and any notes saved by the user.
